# 우리 결혼 OS (노션 연동 사이트)

노션 '우리 결혼 준비' 페이지의 표를 읽어서 레트로 창 모양으로 보여 주는 사이트예요.
체크리스트를 누르면 노션의 '상태'도 같이 바뀌어요. 나머지는 읽기만 해요.

## 왜 서버 파일(api/)이 필요한가요
노션 API는 브라우저에서 직접 부를 수 없고, 토큰을 HTML에 넣으면 누구나 볼 수 있어요.
그래서 `api/notion.js`, `api/toggle.js`가 Vercel 서버에서 토큰을 들고 대신 노션과 이야기해요.

## 올리는 순서 (10분)
1. https://www.notion.so/profile/integrations 에서 '새 API 통합'을 만들고, 이름은 아무거나, 권한은 '콘텐츠 읽기 + 콘텐츠 업데이트'로 해요. 만들면 나오는 **시크릿 토큰**을 복사해요.
2. 노션 '💍 우리 결혼 준비' 페이지 오른쪽 위 ··· → '연결' → 방금 만든 통합을 추가해요. (하위 표가 모두 함께 연결돼요.)
3. 이 폴더 전체를 새 GitHub 저장소에 올려요. (기존 `wedding` 저장소와 따로 두는 걸 권해요.)
4. Vercel에서 그 저장소를 Import → Settings → Environment Variables에 `NOTION_TOKEN` = 복사한 토큰을 넣고 Deploy 해요.
5. 배포 주소를 열어 맨 아래에 '노션 연결됨'이 보이면 끝이에요. '저장본'이라고 나오면 2번 연결이나 토큰을 다시 확인해요.

## 알아둘 점
- 노션 표의 열 이름(예: 할 일, 상태, 시기, 마감일)을 바꾸면 사이트에서 안 보여요. 열 이름은 그대로 두고 값만 고쳐요.
- 표를 새로 만들면 `api/_notion.js` 위쪽 `DB`에 그 표의 주소 끝 32자리를 바꿔 넣어야 해요.
- 사이트 주소를 아는 사람은 누구나 볼 수 있어요. 주소는 공유하지 않거나, Vercel의 Password Protection(유료)을 쓰세요.
- 체크 저장은 '체크리스트 표의 상태'만 바꿀 수 있게 막아 두었어요.
- 노션을 고친 뒤 최대 1분 안에 반영돼요. 바로 보려면 '새로고침' 버튼을 눌러요.
